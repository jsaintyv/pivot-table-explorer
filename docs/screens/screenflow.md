# Screen Navigation Flow

This document describes how users navigate between different screens in the Pivot Table Explorer application.

# Screens

## Main Screen
The entry point and primary interface of the application.
- Allows loading data from multiple CSV files
- Provides access to the Axe Screen
- Provides access to the View Grid Screen

[Main Screen documentation](/docs/screens/main/screen.md)

## Dimensions Screen
Allows users to configure which columns from source CSV files will be used as axes (dimensions) for pivoting data.
- Allows identifying and configuring axes from the data source
- Allows returning to the Main Screen

[Dimensions Screen documentation](/docs/screens/dimensions/screen.md)

## View Grid Screen
Allows users to configure the pivot table structure by defining row dimensions, column dimensions, filters, and value fields.
- Allows configuring row dimensions, column dimensions, filters, and value fields to display in the pivot table
- Allows returning to the Main Screen

[View Grid Screen documentation](/docs/screens/view-grid/screen.md)
