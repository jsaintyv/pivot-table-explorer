# Goal
Describes how to navigate between screens.

# Screens

## Main screen
First screen.
Allows loading data from multiple CSV files.
Allows access to the axe screen.
Allows access to the view grid screen.
[Main screen](/docs/screens/main/screen.md)

## Axe screen
Allows identifying axes in the data source.
Allows returning to the "Main screen".
[Axe screen](/docs/screens/axe/screen.md)

## View grid screen
Allows configuring row dimensions, column dimensions, filters, and value fields to display in the pivot table.
Allows returning to the "Main screen".
[View grid screen](/docs/screens/view-grid/screen.md)
