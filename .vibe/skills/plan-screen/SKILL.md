# Goal 

Plan the screen documentation.

# Steps
1. Analyse docs/screens/ and understand the structure of the documentation
2. Ask the user which screen to realize or to complete
3. Analyse react src/screens/ and create or complete the screen documentation
4. Ask the user to clarify any missing information or to validate the documentation. Ask questions & make suggestions , you will valide with the user.
5. Create or update a subfolder in docs/screens/ 
6. Complete docs/screens/workflow.md with the new screen documentation link
